# Java Atlas

Free visual Java study app: https://ditanraai.github.io/java-atlas-study/

This repository contains the compiled website and three project starters. The lessons are public. Personal notes, progress, reviews and project milestones are saved only in each visitor’s browser, never in this repository. Export JSON in Study data & sources to keep a backup or move to another device.

The private java-atlas repository contains the editable source. Build with npm run build:pages, then copy pages-dist into this repository and push main. GitHub Pages publishes main at the repository root.
